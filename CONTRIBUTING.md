# Contributing to MasteryPath

Thank you for your interest in contributing to **MasteryPath**! We welcome contributions from everyone, whether you're a seasoned developer or just starting your journey in skill mastery.

## How to Contribute

1.  **Fork the Repository**: Click the "Fork" button at the top right of this page.
2.  **Clone your Fork**:
    ```bash
    git clone https://github.com/YOUR_USERNAME/MasteryPath.git
    ```
3.  **Create a Branch**:
    ```bash
    git checkout -b feature/skill-analytics-dashboard
    ```
4.  **Make your Changes**: Implement your feature or fix.
5.  **Commit your Changes**:
    ```bash
    git commit -m "Add skill analytics dashboard feature"
    ```
6.  **Push to your Fork**:
    ```bash
    git push origin feature/skill-analytics-dashboard
    ```
7.  **Open a Pull Request**: Go to the original repository and click "Compare & pull request".

## Development Guidelines

-   **Code Style**: Follow the existing code conventions (Go formatting, React Native best practices)
-   **Commits**: Write clear, descriptive commit messages following conventional commits format
-   **Testing**: Add tests for new features when applicable
-   **Documentation**: Update relevant documentation for significant changes
-   **Issues**: If you find a bug or have a feature idea, please open an issue first

## Areas for Contribution

We especially welcome contributions in these areas:

-   **📊 Data Visualization**: New chart types or analytics features
-   **🎨 UI/UX Improvements**: Enhanced user interface and experience
-   **⚡ Performance**: Optimization of data processing or rendering
-   **🧪 Testing**: Unit tests, integration tests, or E2E tests
-   **📝 Documentation**: Tutorials, guides, or code documentation
-   **🌐 Internationalization**: Translations and localization

## Community

Be kind, respectful, and constructive. MasteryPath is built to help people grow—let's maintain that spirit in our community!
